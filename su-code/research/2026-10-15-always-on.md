# Always-on office: Feynman (auto/deep research), agent-sprite-forge (animation), XERJ + Rust/wasm (token/RAM)

Question: Học gì từ Feynman, agent-sprite-forge, XERJ và Rust/wasm cho "không ai rảnh", critic chọn thay owner, office động và hook nhẹ?
Date: 2026-10-15 · Ship: `su-code/ship/always-on-office/` · Evidence notes (local, not committed): `~/tmp/rd/{feynman,asf,xerj}-notes.md`.
Method: shallow clone, read-only, no binary run. Every claim below cites file:line of the pinned commit.

## Recommendations

| Topic | Call | Why (source) |
|---|---|---|
| Feynman deep-research pipeline (plan → scale → gather → draft → cite → verify → review → deliver, files only) | **Adopt (ideas)** | 7 steps with file artifacts, "Never end with chat-only output" (prompts/deepresearch.md:11-20). Our `/deep-research` skill already has the same shape. R&D idle rung now points at it. |
| Feynman verifier → adversarial reviewer FATAL/MAJOR/MINOR | **Adopt** | Reviewer "Keep looking after you find the first major problem" (.feynman/agents/reviewer.md:12-32). This is our new `critic` agent's grading, used to pick options for the owner. |
| Feynman right-sizing (no fan-out for "what is X"; 2–6 researchers by breadth) | **Adopt** | prompts/deepresearch.md:38-48. Keeps idle research cheap. |
| Feynman "continuous / idle" research | **Not available, build our own** | `/watch` and `/jobs` were removed: no scheduler (RELEASES.md:358, src/cli.ts:99). `/autoresearch` is a foreground bounded loop with up-front approval (prompts/autoresearch.md:9-47). We run it in the `ccc hook idle` ladder (rung 3 R&D, rung 5 lead) under the existing rails: lease on subscription, $/hour cap, MAX_BLOCKS, OFF by default. |
| Feynman telemetry | **Skip (do not install)** | PostHog on by default (README.md:66). |
| agent-sprite-forge: per-frame `duration_ms`, 4-frame walk at 150 ms, idle 4 frames [220,180,220,180] | **Adopt (ideas, art ours)** | pixelspec.md:100-109; examples walker16x24 / hero.anim.json. |
| ASF FX language: dust, flash, ring; deterministic seeded particles; "shrink and cool, never alpha-fade" | **Adopt (small subset)** | fx-language.md:48-69. Dust on walker arrival, flash on done. |
| ASF host-driven time (no timers inside renderers) | **Adopt** | fx-template.mjs:304, fx_verify.mjs:35. Matches our one shared rAF; the walker's own setInterval moves onto it. |
| ASF Python/Pillow sprite pipeline | **Skip** | Build-time Python is not in our stack; code-drawn frames already work (apps/hq-ui/lib/sprite/frames.ts). |
| XERJ (search server, "40x fewer tokens") | **Skip** | "40x" appears in no doc or benchmark of the repo; README says 2.7x output tokens, case study says 1.5x, field reports "~5x" are anecdote (README.md:24-29, CASE_STUDY.md:3-17, user-feedback/…/2026-08-11:3-12). Measurement harness not in repo (benchmarks/grep-vs-retrieval-lucene/README.md:10-15). Needs a daemon, 27–31 MB RC binary, outbound features (xc.rs:604). Same RAM trap we already hit with cbm (KNOWLEDGE.md:410). |
| Rust hook fast path (`ccc hook` before clap) | **Trial** | main() builds the whole clap tree before any hook (crates/cli/src/main.rs:170-190). Hooks cost ~60–65 ms vs a ~42–50 ms spawn floor on Windows (stale v0.66 exe, 3 runs, noisy). Upside ≤ ~15 ms/call, not measured on 0.87: profile on CI first. |
| Typed borrowed hook input instead of `serde_json::Value` | **Skip unless a profile shows it** | Payloads are small (guard.rs:32). |
| Wasm (renderer or hooks) | **Skip** | Canvas 2D + one rAF + offscreen frame cache is enough for ≤8 sprites/room. XERJ's wasm crate is an ingest plugin, not a speed trick (engine/crates/xerj-wasm/src/lib.rs:1-5). Revisit only if a browser profile shows frame drops. |

## What shipped from this brief
- `ccc hook idle`: R&D teammate (name rd/research/explore) out of tasks → `/deep-research` on the first STATE `Next` item with no brief in `su-code/research/`, then `/planning` + ONE AskUserQuestion with Recommended.
- `8sync ccc delegate on`: product/technical questions go to the `critic` agent (FATAL/MAJOR/MINOR) instead of the owner; Ship, secrets, destructive/paid/deploy/merge/release and high-risk stay with the owner.
- `hook session-start`: "Phòng của bạn" from the session name + "Phòng khác đang làm".
- HQ office: Critic seat, sprites with role props for every seat, per-state frame timing, breath/blink, 4-frame walker, dust/flash on the shared rAF.

## Patterns (derived from sources above; my synthesis, marked as such)
- Collapsible step with status icon + auto-open on error/running, auto-close on done (S2,S3). Use per tool call. Pitfall: many completed tools open by default -> scroll wall; consider collapsing done.
- Plan/task list with 4 states + counter (S1,S14,S7). Use for top-level progress; keep to one list not per-message.
- Summary line of edits (files/lines) + separate review surface w/ per-hunk accept (S4); checkpoint inline with compare/restore (S6).
- Agent roster panel with collapse of idle (S7) - noise control for multi-agent.
- Message between agents: S7 uses direct-message into transcript view (open teammate, Enter) + idle notification carrying final answer; task list with dependencies for handoff; S8 handoff_span (from/to) as a typed node in span tree; S10 graph with nodes+loop cycles; S13 elicitation/response activity types as the human-visible handoff. No source found showing swimlane or avatar-thread for agent-to-agent messages.

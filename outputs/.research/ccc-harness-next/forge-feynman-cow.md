## Features: what it does -> Claude Code-native rebuild -> value / effort

### A. Worth building (ranked)

1. **Pending-todos stop check (Forge S1-S4)**: at turn end, if the task list still has pending/in_progress items, push them back once per distinct set (S2). CC: extend the kit's native Stop gate (`ccc/gate.rs`) with a task-list check (TaskCreated/TaskCompleted hooks can mirror state to a session file), de-duplicated by set. Zero-code alternative: `/goal all task-list items completed and tests green` (S40). Value high, effort low. Must defer while background agents run (S40), as 0.66.0 already does.
2. **Loop breakers, 3 tiers (Cow S29 + Forge S5)**: PreToolUse + PostToolUseFailure command hooks with a per-`session_id` (and `agent_id`) ring buffer of 50 (tool, args-hash, ok). 3 identical calls -> `additionalContext` nudge with Forge's text (S5); 5 identical -> `permissionDecision: deny` with reason; 6/8 failures -> deny and tell the user to rephrase/split. Also catches A,B,C cycles. Value high (token burn), effort low-medium (~100 lines Rust in `ccc/`, unit-testable).
3. **Evolution review with a "default SILENT" rule (Cow S23-S26)**: do NOT port the idle daemon. CC: SessionEnd/PreCompact command hook only appends a transcript pointer to a queue file (fits the 1.5 s budget, S41); an on-demand `/evolve` skill (or Routine) runs a Haiku/Sonnet subagent that may patch a kit skill, finish a promised deliverable, or append one bullet to `su-code/KNOWLEDGE.md`, with the "Do NOT capture" list (S25) as hard rules; git is the undo (replaces S26 snapshots); edits only inside the project dir. Value high, effort medium. Compliance: run inside the user's own Claude Code session; unattended `claude -p` only on a Console key (headless-on-subscription "not verified", plan section 6). Privacy: transcripts can hold client data; local only, redact secrets, one client per run.
4. **Memory consolidation "Deep Dream" (Cow S27)**: weekly `/consolidate` skill (or Routine/Desktop scheduled task) that merges `su-code/KNOWLEDGE.md`, resolves conflicts (newer wins), caps at N lines, never adds facts not in the source. The SessionStart digest (0.66.0) stays byte-stable and small. Value medium-high, effort low (skill + size lint in `8sync doctor`).
5. **Before/after eval rule for prompt changes (Feynman S15)**: deterministic scorer, same model and task ids, both result files committed. CC: tie to the Phase 1 bench; rule "any change to kit agents/skills/CLAUDE.md block ships with before/after bench rows". Value high, effort medium.
6. **Knowledge wiki skill (Cow S28)**: `knowledge/<cat>/<slug>.md` + `index.md` + `log.md`, mandatory `> Source:` line, links only to existing pages; PostToolUse(Write) lint hook. Pairs with deep-research provenance. Value medium, effort low. Local files only (local-first, client data separate).
7. **Plan-file contract + lint (Forge S44-S45)**: see Planning section; value medium-high, effort low.
8. **Tool-error reflection (Forge S7)**: PostToolUseFailure `additionalContext` with the 3-step reflection once per failing (tool,args); merge into item 2. Value low-medium, effort low.
9. **Steer/cancel semantics (Cow S30-S31)**: CC already queues typed input and has Esc; relevant only to a Discord/Channels bridge (`8sync hq`): `/cancel` must bypass the bridge's own queue; `/steer` only while a run is active, bounded 16 msgs / 8000 chars. Value low-medium, effort low, only if hq grows a command surface.
10. **Untrusted package hygiene (Cow S34, Forge S12)**: only if 8 Sync ships a community-skill installer: refuse traversal/symlinks, size caps, built-ins read-only, trust prompt for project `.mcp.json` (CC has its own approval; `ccc policy --lock-mcp` shipped). Value low now, effort low.

Bật một lệnh, cả team AI làm.
Mọi thứ còn lại ở HQ.

Mỗi việc là một phòng (một session Claude Code chính chủ, hoặc omp). Terminal chỉ để bật/tắt. Giao việc, trả lời câu hỏi, xem phòng nào đang làm hay kẹt — mở HQ trên máy, hoặc qua link internet từ điện thoại.

1Cài

Một dòng lệnh, có sẵn Claude Code + kit 8sync + omp.

2Mở phòng

8sync ccc . dev, 8sync ccc . qa… mỗi phòng một tab terminal.

3Bật

8sync ccc auto on rồi 8sync hq ui. Xong — phần còn lại làm trên HQ.

Cài và cập nhật

# Linux / macOS
curl -fsSL https://8-sync-dev.github.io/su-code/install | sh
# Windows PowerShell
irm https://8-sync-dev.github.io/su-code/install.ps1 | iex

claude auth login     # đăng nhập Claude Code một lần (tài khoản của bạn)
8sync up              # cập nhật 8sync + kit (chạy khi có bản mới)

Bật / tắt — toàn bộ lệnh cần nhớ

Chạy trong thư mục dự án. Mọi thứ khác đều có nút trên HQ.

ViệcLệnh
Mở / quay lại một phòng Claude Code8sync ccc . <tên>
Bật team tự làm (mọi dự án trên máy)8sync ccc auto on
Chỉ dự án ở thư mục này8sync ccc auto on --here
Thêm đội omp chạy song song8sync ccc auto on --omp · tắt đội omp: 8sync ccc auto omp off

Mở HQ qua internet (điện thoại, máy khác)8sync hq ui --public
Tắt nhật ký HQ8sync hq ui --off
Khi auto bật, các phòng không đứng chờ:
  • Câu hỏi không ai trả lời sau 1 phút (bạn không gõ gì vào phòng đó): câu hỏi hiện trên HQ để bạn bấm chọn; hết 1 phút thì agent critic chọn thay và ghi vào su-code/DECISIONS.md.
  • Hỏi quyền khi bạn vắng: hiện trên HQ với nút Cho phép / Từ chối; hết giờ thì tự từ chối kèm hướng dẫn để phòng đi đường khác — không bao giờ tự cho phép.
  • Kẹt vì lỗi API hay hết usage: phòng tự chạy lại — lỗi tạm thời thì thử lại sau vài phút, hết usage thì chạy lại đúng giờ reset (HQ ghi “tự chạy lại lúc HH:MM”).
  • Nhiều phòng, hai đội: các phòng nhận đích chung, họp standup, và nhắn nhau (cả phòng ccc lẫn phòng omp).

HQ — làm mọi thứ khác ở đây

8sync hq ui mở trình duyệt. Mỗi phòng một bàn làm việc; thấy ngay phòng nào đang làm, chờ bạn, hay kẹt.

Đang chờ anhCâu hỏi và yêu cầu quyền của các phòng, có đếm ngược. Bấm một lựa chọn là phòng chạy tiếp.
Giao việc · Gửi mọi phòngGõ việc cho một phòng hoặc cả dự án (cả đội ccc và đội omp). Phòng đang rảnh nhận ngay, phòng đang bận nhận khi xong lượt.
Auto · Đội ompNút Chạy / Tạm dừng và công tắc bật đội omp — thay cho gõ lệnh.
Board · Chat · Báo cáoBảng task, tin nhắn giữa các phòng, chi phí và việc đã xong.
Usage% usage 5 giờ / 7 ngày và giờ reset (lấy từ status line của Claude Code).
Link internet: 8sync hq ui --public in một link https://…trycloudflare.com/api/login?k=… (cần cloudflared; thiếu thì lệnh in cách cài). Ai có link là điều khiển được các phòng trên máy bạn — đừng chia sẻ. Link chết khi tắt HQ; mỗi lần bật là một link và khoá mới.

Đội omp

Mặc định chỉ đội Claude Code (ccc). Thêm đội omp khi cần chạy lâu hơn hoặc chia việc cho model khác.

8sync ccc auto on --omp      # bật cả hai đội
8sync . rd-omp               # mở một phòng omp (mỗi phòng một tab)
8sync ccc auto omp off       # chỉ tắt đội omp
  • Phòng omp nhận việc từ HQ, nhận đích chung, tự chạy lại khi provider báo hết quota, và nhắn được cho phòng ccc (và ngược lại) qua 8sync ccc msg <phòng> "…" — agent tự dùng, bạn không cần gõ.
  • omp dùng model của bên thứ ba (GLM, OpenAI…) hoặc API key Console của Anthropic. Đăng nhập gói Claude (Pro/Max/Team) chỉ dùng trong Claude Code — phòng omp chạy model anthropic theo kiểu đăng nhập gói sẽ không được tự động hoá.

An toàn và luật dùng Claude

  • Luôn hỏi bạn: câu “Ship” (merge, release, deploy), secret / đăng nhập, xoá / không hoàn tác, tiền, và quyết định rủi ro cao (pháp lý, y tế, tuyển dụng, tín dụng).
  • Không bao giờ tự cho phép một yêu cầu quyền; không dùng chế độ bỏ qua quyền. Guard của kit chặn lệnh phá dữ liệu, force-push, in/đẩy .env.
  • Usage đọc từ dữ liệu Claude Code gửi cho status line — 8sync không đọc, lưu hay chuyển token đăng nhập Claude.
  • Chạy liên tục nhiều ngày khi vắng máy: dùng Routines của Claude Code, hoặc đội omp với API key — xem /rules trong Claude Code.
  • Trong Claude Code: /rules (được phép không) · /sec (quét secret) · /aup-audit (repo so với Usage Policy).

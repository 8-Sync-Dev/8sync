## Cơ chế vi phạm rule (KHÔNG port, cần cờ)

1. HUD usage monitor dùng token subscription ngoài Claude Code: `src/hud/usage-api.ts` dòng 1-60 đọc credential OAuth của Claude Code từ macOS Keychain "Claude Code-credentials" hoặc `~/.claude/.credentials.json`, gọi `api.anthropic.com/api/oauth/usage`, và còn refresh token qua `platform.claude.com/v1/oauth/token` với OAuth client_id của Claude Code (dòng 49-59, 1109-1135) rồi ghi ngược credential (`writeBackCredentials`, dòng 1517). Đây là tool bên thứ ba cầm token subscription và đứng vai client: trái rule ccc "token subscription chỉ dùng trong Claude Code chính chủ", đồng thời đụng secret. Dùng chỉ số `rate_limits` mà Claude Code đã đưa vào statusline JSON (đúng như `ccc report`). Cùng file còn có nhánh đổi `ANTHROPIC_BASE_URL` sang z.ai/MiniMax/Kimi (backend không phải Anthropic).
2. `src/cli/launch.ts`: cờ `--madmax/--yolo` ánh xạ sang `--dangerously-skip-permissions` (dòng 51, 791) và đoạn sao chép `oauthAccount` giữa các `.claude.json` (dòng 272-380). ccc cấm `bypassPermissions`. Không port.
3. `src/features/rate-limit-wait/*`: daemon quét nội dung pane tmux bằng regex ("rate limit", "please wait"...) và tự gõ `1` + Enter để tiếp tục (`tmux-detector.ts` 34-60, 585-625). Không phải giả client, nhưng là tự động hóa phím trên client chính chủ để chạy vòng quanh giới hạn, không có owner. Không port; `ccc idle` dùng lease khi owner có mặt.
4. `src/notifications/reply-listener.ts`: nhận tin từ kênh chat ngoài và bơm vào pane `claude` bằng `send-keys`. Có allowlist fail-closed, sanitize 2 lớp, rate limit (dòng 1-30, 981-987) nhưng vẫn là đường prompt-injection từ ngoài vào phiên có quyền; không port. Dùng HQ inbox (masked, kéo khi rảnh).
5. `docs/OPENCLAW-ROUTING.md`: event payload kèm `tmuxTail` (nội dung pane) gửi ra gateway ngoài: rủi ro lộ data client; không port.
6. `/ask codex|gemini|...`, `omc team N:codex|gemini`: dùng CLI của nhà khác với credential của họ. Không vi phạm rule Anthropic nhưng ngoài phạm vi ccc; không port (không thấy dấu hiệu reverse-engineering Claude Code trong phần đã đọc, nhưng chưa quét toàn bộ `bridge/*.cjs` đã bundle, not verified).

Không thấy trong phần đã đọc: sao chép system prompt Claude Code, proxy lại request Anthropic, giả User-Agent. Chưa quét hết `bridge/` (bundle) và `src/providers` (GitHub/GitLab/Bitbucket/Azure DevOps/Gitea, không liên quan Anthropic).
